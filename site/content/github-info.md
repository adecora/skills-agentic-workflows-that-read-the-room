## Recent updates worth watching

- **Copilot code review effort levels are generally available.** Choose "Lite" for routine changes or "Balanced" for larger, more complex, or sensitive pull requests, letting review depth match the risk of the change. Source: [GitHub Changelog](https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available/).
- **Pin saved views to the repository issues sidebar.** Your most-used saved views are now one click away, even when the sidebar is collapsed, making it faster to jump between filtered issue lists. Source: [GitHub Changelog](https://github.blog/changelog/2026-08-20-pin-projects-views-and-milestones-to-the-repository-sidebar/).
- **Convert branch protection rules to repository rulesets automatically.** A new one-click migration in repository settings maps existing branch protection configurations (required reviews, status checks, push restrictions) into rulesets, GitHub's more flexible governance framework. Source: [GitHub Changelog](https://github.blog/changelog/2026-08-11-automatically-migrate-branch-protection-rules-to-repository-rulesets/).
